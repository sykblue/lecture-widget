사용법
  1. 다른 탭에서 ZEP 강의실을 열고 소리가 나오게 둡니다.
  2. ▶ 시작 → 공유 창에서 Chrome 탭 → ZEP 탭 선택 → 탭 오디오도 공유 켜고 공유.
  3. ⧉ 띄우기를 누르면 항상 위에 뜨는 작은 창이 돼요.
처음 한 번은 받아쓰기·요약 모델을 내려받느라 시간이 걸려요 (이후엔 브라우저에 저장).

설정

웹페이지에서 Ollama를 쓰려면 한 번만 설정이 필요해요.
Windows: setx OLLAMA_ORIGINS "*" 실행 후 Ollama 재시작
Mac: launchctl setenv OLLAMA_ORIGINS "*" 실행 후 Ollama 재시작

소리와 글은 이 브라우저 밖으로 나가지 않아요. 인터넷은 모델을 처음 받을 때만 써요. Chrome 또는 Edge 최신 버전에서 쓰세요.
